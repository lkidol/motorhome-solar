# 3dassets.dev

> A free, open marketplace of web-optimised GLB models for three.js, Blender, Godot, Unity and any glTF-capable tool. Every asset is validated, re-encoded (quantized geometry, WebP textures) and human-reviewed. New uploads use CC0 1.0 Universal: free for personal and commercial use without attribution. Contributors must accept the CC0 dedication.

Browse by category (what it is), theme (what world: sci-fi, fantasy, modern…) and style (what look: low-poly, realistic, voxel…). Assets load with a plain three.js GLTFLoader; no Draco or KTX2 loaders are required. Direct CDN URLs are CORS-enabled and immutable.

## For agents

- Start here: [3dassets skill](https://3dassets.dev/skill.md): search, connect an account, upload GLBs and check review status
- Install the skill into any agent that reads SKILL.md: npx skills add 3dassets-dev/3dassets (source: https://github.com/3dassets-dev/3dassets)
- MCP server (Streamable HTTP): https://3dassets.dev/mcp, or over stdio with npx -y 3dassets-mcp (npm package 3dassets-mcp; official MCP Registry name dev.3dassets/catalogue). Tools: search_assets, search_packs, get_pack, list_demos, get_demo, get_asset, get_asset_usage, list_categories, list_tags, list_licenses, list_ai_models, create_account, verify_account, submit_asset_from_url, get_upload_url, finalize_upload, my_assets, update_asset, submit_pack, my_packs
- Model attribution: https://3dassets.dev/api/v1/ai-models (OpenRouter suggestions, refreshed hourly); MCP list_ai_models. Submit aiGenerated and optional aiModel; custom names accepted, omit unknown names.
- REST API v1: https://3dassets.dev/api/v1. OpenAPI at https://3dassets.dev/api/v1/openapi.json
- Rate limits: the same with or without a key (counted per API key, per IP without one). Reads 10,000/min, downloads 2,500/min, submissions 60/min. Over the limit: HTTP 429, code RATE_LIMITED, honour Retry-After. Fetch what a project needs; catalogue-wide mirroring is not permitted. Details: https://3dassets.dev/docs/api#rate-limits
- Auth for writes: `Authorization: Bearer <api-key>` (accounts: POST https://3dassets.dev/api/v1/accounts, then /verify with the emailed code)
- Every asset has a Markdown view at https://3dassets.dev/assets/{slug}.md and JSON at https://3dassets.dev/api/v1/assets/{slug}
